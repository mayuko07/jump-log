# jump LOG

レッスンの予約メールや日々の記録をもとに、フィットネスの受講履歴を整理・分析するための個人開発アプリです。

React Native、Expo、TypeScriptを使用し、スマートフォンでの利用を想定して開発しています。

## 1. 開発背景

フィットネスの受講履歴を振り返る際、過去のレッスン情報を一覧で確認したり、インストラクターやプログラムごとの受講状況を集計したりすることが難しいと感じたことが開発のきっかけです。

そこで、予約メールから取得できる情報と、自分で入力する受講実績を組み合わせ、記録・集計・可視化できるアプリを開発しています。

## 2. 主な機能

### レッスン記録

- レッスン情報の登録・確認
- 受講履歴の一覧表示
- カレンダーによる記録の確認
- 受講状況やメモの手動入力

### データの集計・可視化

- インストラクター別の集計
- プログラム別の集計
- スタジオ別の集計
- 体重・体脂肪率などの記録とグラフ表示
- 一定期間の記録の振り返り

### Gmail連携

Gmail APIを利用し、予約に関するメールからレッスン情報を抽出する処理を実装しています。

予約・確定・キャンセルの情報を区別し、メールの受信だけで実際に受講したと判断しない設計にしています。

現時点では、PC上のスクリプトによるGmail連携処理を開発しており、スマートフォン上での認証・同期は検証途中です。

## 4. 設計・実装上の工夫

### 予約情報と受講実績の分離

予約完了メールが存在しても、実際にレッスンを受講したとは限りません。

そのため、メールから取得した予約状態と、利用者が記録する受講実績を区別しています。

キャンセル情報も考慮し、予約件数をそのまま受講回数として集計しないようにしています。

### メール解析処理の分離

メール本文の解析、レッスン情報の管理、集計処理を別々のモジュールに分けています。

これにより、メールの形式変更や集計項目の追加に対応しやすい構成を目指しています。

### Gmailの差分同期

Gmailの履歴情報を利用し、前回の同期以降に変更されたメールを取得する処理を実装しています。

履歴情報が利用できなくなった場合を考慮した処理も設けています。

### 記録データの可視化

保存したデータを単に一覧表示するだけでなく、受講傾向や身体データの変化を確認できるようにしています。

## 7. 注意事項

- 個人開発の非公式アプリであり、フィットネス運営会社の公式アプリではありません。
- Google OAuthの認証情報、アクセストークン、メール本文などの個人情報はリポジトリに含めません。
- Gmailへのアクセスには利用者自身の認証設定が必要です。
- 開発途中のため、一部機能は実機での動作検証が完了していません。

## 8. 開発目的

実際に感じた不便さを出発点に、情報の取得、整理、保存、集計、可視化までを一つのアプリとして実装することを目指しています。

特に、予約と受講実績のように意味の異なるデータを区別し、集計結果が実態と一致するように設計することを重視しています。


## 9. ローカルでの起動方法

### 必要な環境

- Node.js
- npm
- Expo

### セットアップ

1. リポジトリをダウンロードします。
2. プロジェクトのフォルダで依存パッケージをインストールします。

```bash
npm install
```

3. サンプルデータをコピーします。

Windows PowerShellの場合：

```powershell
Copy-Item .\src\data\lessonData.example.ts .\src\data\lessonData.ts
```

4. 開発サーバーを起動します。

```bash
npx expo start
```

### データの取り扱い

`lessonData.ts` は個人のレッスン履歴を保存するため、
GitHubでは公開していません。

代わりに、架空のレッスン情報を含む
`lessonData.example.ts` を公開しています。

Gmail連携には別途Google OAuthの認証設定が必要です。
認証情報はGitHubに含めていません。
